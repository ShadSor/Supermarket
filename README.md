# Симуляция работы супермаркета

Программа моделирует работу супермаркета: управление товарами на складе и в торговом зале, списание просроченных товаров, установка скидок, покупки и случайные события. Проект написан на Java с использованием графического интерфейса Swing.

## Особенности

- **Два режима работы:**
    - **Интерактивный режим** — пользователь управляет действиями вручную.
    - **Режим наблюдателя** — симуляция проходит автоматически, события генерируются случайно.
- Поддержка двух типов товаров:
    - `UnitProduct` — товары, продающиеся поштучно (например, бутылка молока).
    - `WeightedProduct` — товары, продающиеся по весу (например, колбаса на вес).
- Автоматическое удаление просроченных товаров.
- Поддержка скидок (в процентах).
- Генерация событий: завоз, перемещение, скидки, покупки.
- Графический интерфейс с логом событий и таблицей товаров.
- Автоматическое завершение симуляции по таймеру.

## Архитектура проекта

Проект разделён на пакеты:

- `supermarket.model` — базовые классы товаров (`Product`, `UnitProduct`, `WeightedProduct`).
- `supermarket.store` — классы склада (`Warehouse`), торгового зала (`ShopFloor`) и самого супермаркета (`Supermarket`).
- `supermarket.events` — `EventGenerator`, генерирующий случайные события.
- `supermarket.ui` — графический интерфейс на основе Swing (`SwingUI`, `ObserverWorker`).
- `supermarket.config` — конфигурация (загрузка из файла `config.properties`).
- `supermarket` — точка входа (`Main.java`).

## Запуск

1. Убедитесь, что в корне проекта есть файл `config.properties` со следующим содержанием:
   properties INITIAL_WAREHOUSE_ITEMS=10 SIMULATION_TIMEOUT_MS=30000
   (При необходимости измените значения.)

2. Скомпилируйте и запустите проект:
   bash javac -d out src/**/*.java java -cp out supermarket.Main

3. В консоли введите:
    - `Хочу играть!` — для запуска в интерактивном режиме.
    - `Я наблюдатель` — для запуска автоматической симуляции.

## Управление

### В интерактивном режиме доступны кнопки:
- **Со склада в зал** — переместить 3 товара со склада в торговый зал.
- **Удалить просрочку** — списать все просроченные товары.
- **Установить скидку** — ввести процент скидки (0–100%), применяется ко всем товарам.
- **Случайное событие** — запустить одно из случайных событий (аналогично режиму наблюдателя).

### В режиме наблюдателя:
- События происходят автоматически каждые 2 секунды.
- Кнопки отключены.
- Симуляция завершается через 30 секунд (настраивается в `config.properties`).
